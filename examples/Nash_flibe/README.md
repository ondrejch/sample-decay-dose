# Nash Flibe

Example case under `examples/`.

**Scripts**
- `lif_coa2.py` — Example use case of SampleDose - short irradiation (10 s, 2e11 n/cm2/s) of a lithium sample
  with trace Na, Mg, Ca, Ag, Ba, Rb and Sr, followed by 600 s of decay

**Run**
- From this directory: `python <script>.py`
- Needs a user-supplied `B.f33` next to the script.
- SCALE inventory files (`*.f71` / `*.f33`) are user-supplied and gitignored.
