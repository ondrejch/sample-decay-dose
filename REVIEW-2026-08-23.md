### Issue 1 -- Severity: suggestion

- File: `pyproject.toml:37`
- Description: `[tool.setuptools.packages.find] include = ["sample_decay_dose*"]` is stricter than the deleted `setup.cfg` `packages = find:`. `setuptools.find_packages()` from the repo root still discovers `leaky_box_origen` as a top-level package, but the new filter excludes it. `pip install ./` (documented in README and AGENTS.md) therefore no longer installs `leaky_box_origen`, and `[tool.setuptools.package-data]` only ships `sample_decay_dose/data/*.json` and `*.html` — the newly tracked DCF CSVs under `leaky_box_origen/data/` are not package data either. - Suggestion: Include `leaky_box_origen*` in `packages.find` (or document that leaky-box is repo-local only) and add `leaky_box_origen = ["data/*.csv"]` to package-data if it should work after `pip install`.
- Status: fixed in `913851d` (`leaky_box_origen*` in `packages.find`, DCF CSVs in package-data).

### Issue 3 -- Severity: suggestion

- File: `leaky_box_origen/LeakyBox.py:113`
- Description: `DecayBoxA.run_decay_sample` and `DecayBoxB.run_decay_sample` (`leaky_box_origen/LeakyBox.py:245`) now raise `RuntimeError` on a failed SCALE run, but they `os.chdir(self.case_dir)` without a `try`/`finally`. On failure the process is left inside `_box_A` / `_box_B_*` / `_box_C_*`. `SampleDose` ORIGEN/MAVRIC runners in the same series wrap the chdir in `try`/`finally` and restore `self.cwd`; irradiator.py does too. The default LeakyBox `main()` path is mostly saved by `_in_directory()`’s `finally`, but any direct `run_decay_sample()` caller that catches the exception (tests, joblib workers, a REPL) keeps the leaked cwd and can write later artifacts into the SCALE case directory.
- Suggestion: Match `SampleDose.run_scale_or_raise` usage: `chdir` inside `try`/`finally`, or call `run_scale_or_raise(..., context_dir=self.case_dir)` from a context that always restores `cwd`.
- Status: fixed in `913851d` (`try`/`finally` around the case-directory `chdir`). Residual gaps (restore of the caller's cwd, `DecayBoxB` test) are tracked in `REVIEW-2026-09-27.md`.
